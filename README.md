# Simple ATM Simulator

A simple ATM simulator developed in C++ that demonstrates Object-Oriented Programming (OOP) concepts and basic banking operations.

## Features

- Deposit money
- Withdraw money
- Check current balance
- Input validation
- Console-based user interface

## Technologies Used

- C++
- Object-Oriented Programming (OOP)

## Concepts Applied

- Classes and Objects
- Encapsulation
- Functions
- Conditional Statements
- Loops
- Input Validation
